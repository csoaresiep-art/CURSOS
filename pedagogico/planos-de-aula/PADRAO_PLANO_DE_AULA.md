# Padrão IEP de Plano de Aula

> Modelo oficial do **IEP Sistema de Ensino** para planos de aula, encontros e módulos EAD.
> Copie este arquivo, renomeie e preencha todas as seções. Seções marcadas como *(quando aplicável)* podem receber "Não se aplica", mas não devem ser apagadas.

**Como nomear os arquivos**

```
pedagogico/planos-de-aula/<nome-do-curso>/
├── README.md                  ← visão geral do curso (carga horária, módulos, cronograma)
├── modulo-01-<tema>.md        ← um plano por módulo, unidade ou encontro
├── modulo-02-<tema>.md
└── pratica-<tema>.md          ← prática, estágio ou projeto final, se houver
```

Use letras minúsculas, sem acentos e com hífens (ex.: `modulo-03-producao-de-materiais.md`).

### Checklist antes de publicar o plano

- [ ] Objetivos são observáveis e ligados a uma evidência.
- [ ] Os tempos da sequência somam a carga horária.
- [ ] Rubrica com pelo menos 3 critérios e 3 níveis.
- [ ] Há versão acessível e alternativa sem internet.
- [ ] Nenhum dado pessoal real de aluno aparece no material.
- [ ] Materiais de terceiros têm fonte e licença conferidas.
- [ ] Gabaritos e provas **não** foram colocados neste repositório público.
